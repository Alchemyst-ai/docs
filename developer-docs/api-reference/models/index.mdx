The Alchemyst chat completions endpoint serves **Big Bull Alpha** by default and
accepts any OpenRouter `provider/model` id when you bring your own key.

## Big Bull Alpha

**Big Bull Alpha**, is the default
Alchemyst-served model. Use it by passing `"model": "Big Bull Alpha"` or by
omitting `model` entirely.

| Property | Value |
| --- | --- |
| Model id | `Big Bull Alpha` |
| Default | Yes |
| Served by | Alchemyst |
| Billing | Free while in launch |

Big Bull Alpha is grounded in the caller's private Alchemyst context through the
server-side `search_context` tool. See
[Chat completions](/api-reference/chat-completions) for the full request
reference.

## OpenRouter models

Pass any OpenRouter `provider/model` id as `model` and provide a provider key via
`llm_api_key`, `api_key`, or `x-llm-api-key`. OpenRouter is an implementation
detail: the endpoint is OpenAI-compatible regardless of which model you select.

```bash
curl -X POST \
  'https://platform-backend.getalchemystai.com/api/v1/context/search/chat/completions' \
  -H 'Authorization: Bearer sk-or-...' \
  -H 'Content-Type: application/json' \
  -d '{
    "email": "you@example.com",
    "model": "openai/gpt-4o-mini",
    "messages": [
      { "role": "user", "content": "Summarize my saved project notes." }
    ]
  }'
```

## List models

| Method | Route | Description |
| --- | --- | --- |
| `GET` | `/api/v1/context/search/models` | List served models. |
| `GET` | `/api/v1/context/search/chat/models` | The same list at the `/chat` base path used by OpenAI SDK clients. |

```typescript
const models = await client.models.list();
console.log(models.data);
```
