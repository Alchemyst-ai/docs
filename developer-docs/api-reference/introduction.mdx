## Authentication

To obtain your **API key**, follow these steps:

1. Go to the **[Alchemyst Platform](https://platform.getalchemystai.com)** and sign up using your **Google account**.
2. After logging in, open the **[API Keys page](https://platform.getalchemystai.com/apikeys)** to generate your API key.
3. You can view and manage your API keys anytime from the same **API Keys** page.

Include your API key in the `Authorization` header on every request:

```bash
curl https://platform-backend.getalchemystai.com/api/v1/context/search \
  -H "Authorization: Bearer <ALCHEMYST_API_KEY>"
```
